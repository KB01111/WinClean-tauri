# WinClean 2.0 Implementation Plan

> **For agentic workers:** Inline execution in this session. Steps use checkbox syntax for tracking.

**Goal:** WinClean 2.0 optimizer suite on the existing Tauri 2 + Rust + React/TS stack for the ASUS ROG Zephyrus G16, preserving scan/cleanup/Drive/AI Insights.

**Architecture:** New Rust modules `src-tauri/src/optimizer/{policy,services,processes,power,hardware,capabilities}.rs` behind Tauri commands in `commands.rs`; additive SQLite tables; typed TS layer `src/lib/optimizer.ts` + feature views; existing `@openai/agents` extended with read-only tools and deterministic validation.

**Tech Stack:** windows-sys 0.61 (SCM, ToolHelp, Power, Registry), React 19, bun test, cargo test.

## Global Constraints

- Non-admin by default; protected services/processes never mutable; snapshot-before/audit/rollback for every mutation; no CUDA/NVAPI/DXGI polling (RTX 4070 sleep); NPU inference only when verified, CPU fallback always.
