# WinClean Support Diagnostics

WinClean diagnostics are local JSON artifacts generated from the Settings view.

## Contents

- App version.
- SQLite database path.
- Current schema version.
- Recent scan run metadata.
- Recent cleanup action history.
- Confirmation that diagnostics are local-only.

## Exclusions

- No file contents.
- No remote uploads.
- No telemetry identifiers.
- No account or cloud data.

Users can share the exported JSON manually when they want support help.
